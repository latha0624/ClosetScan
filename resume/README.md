## Before you apply (required)
1. Replace **Expected [Month Year]** and bachelor **[Graduation Year]**.
2. Add work authorization under contact, one line only:
   - `Authorized to work in the U.S.` **or**
   - `Will require sponsorship`
3. Add **1–2 real metrics** to NTT bullets (only numbers you can defend in an interview).
4. Put live demo / GitHub repo links on Taxidi and KITA if they exist.
5. Confirm GitHub is public and shows real commits before linking it.

## Which title to use
Keep one resume file per target. Change only the title line under your name:

| Target role | Title line |
|-------------|------------|
| Default / most jobs | Full Stack Software Engineer |
| UI-heavy Angular roles | Frontend / UI Engineer (Angular) |
| API-heavy roles | Software Engineer (Node.js / APIs) |
| General SWE | Software Engineer |

Do **not** use “Software Engineer – AI” unless the job is actually AI-focused and you can show shipped AI work.

## Re-export PDF
Open the HTML file in Chrome → Print → Destination: Save as PDF → Margins: Default → Background graphics: off.
