ClosetScan — App Deep Dive for Interview

AI & AR/VR Innovation Intern · Technical demo prep · Latha Prabhakar

What to remember: live RoomPlan + LiDAR demo. Pitch the problem → scan → toggle empty shell → fractional inches → validate vs tape → explain architecture honestly.

1. Problem & product story

Closets are hard to measure by eye, and photos alone do not give usable dimensions for shelving, organizers, or renovation planning. ClosetScan turns a LiDAR iPhone into a closet measuring tool that:

  • Scans the physical closet with Apple RoomPlan (LiDAR + cameras).
  • Digitally hides contents so reviewers see an empty architectural shell.
  • Reports width, depth, and height to the nearest 1/16 inch.
  • Lets you validate those numbers against a steel tape and keep a trial history.

Interview framing: second-round technical demonstration — not a production App Store product. Focus: reproducible demo, clear architecture, honest accuracy.

5. Scan pipeline

RoomPlan returns parametric CapturedRoom: surfaces (walls/floors/doors/windows/openings) + objects. No ceilings array — height from wall extents; viewer adds a thin ceiling lid.

Lifecycle: start → run → Done → stop → processing → captureView(didPresent:) → Notification → handleScanComplete → dimensions + results.

DelegateBridge: RoomCaptureViewDelegate needs NSCoding. Separate NSObject / NSSecureCoding bridge keeps ObservableObject clean and fixes CI — good engineering story.

6. Digital empty shell

Say: “Digital removal is intentional omission. Surfaces always; objects only when Show contents is on. No generative inpainting — reproducible under interview lighting.”

7. Dimension math

  1. Collect surfaces: walls + floors + doors + windows + openings.
  2. 8 local corners (±dimensions/2) → world via transform.
  3. Expand AABB min/max.
  4. Fallback: wall centers ± half dimensions.
  5. Y → height; larger horizontal → width; smaller → depth.
  6. meters × 39.37007874015748 → inches.
  7. Round fraction to nearest 1/16; reduce fraction.
  8. Report confidence + volume ft³.

8. Validation

Signed errors (app − tape). Target when max(|ΔW|,|ΔD|,|ΔH|) ≤ 0.0625". Persist trials in UserDefaults.

Honesty line: Display resolution is 1/16". LiDAR + RoomPlan is typically centimeter-class. Do not claim guaranteed ±1/16" sensor accuracy — measure, report, validate.

9. Device & install

  • LiDAR required; iPhone 16 Pro OK; Simulator cannot capture.
  • Camera + world sensing usage descriptions; arkit + metal.
  • GitHub Actions IPA → Sideloadly (7-day re-sign).

10. Limitations

  • Non-LiDAR phones cannot capture.
  • Narrow/cluttered closets may miss or merge walls.
  • Clothes detection inconsistent; empty shell still shows structure.
  • AABB can overestimate with openings.
  • Width/depth normalized; synthesized ceiling approximate.

11. Strong Q&A

Walk me through the architecture.
SwiftUI phase machine in AppModel. RoomCaptureView scan → RealityKit dollhouse → ClosetDimensions AABB → ValidationStore.
How do you digitally empty the closet?
Omission, not inpainting. Surfaces always; objects when toggle on.
How do you get 1/16 inch?
Meters→inches; round fractional part to nearest sixteenth; validation vs 0.0625".
Is RoomPlan accurate enough?
Centimeter-class. Fractional inches are reporting precision; prove with tape trials.
What would you ship next?
Opening-aware clear span, multi-scan fusion, USDZ export, better ceiling, MAE charts, optional ML clothing segmentation.
Biggest engineering snag?
No ceilings array; DelegateBridge / NSSecureCoding for CI.
Why not raw ARKit mesh?
Parametric surfaces give a cleaner empty-shell story and stabler demo dimensions.
